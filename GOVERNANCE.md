# LLM-Systems-Lab — Governance

This repository is a **navigation hub and research map** for post-training, reward modeling, alignment, multimodal judges, and model evaluation. It does not absorb or duplicate the source tree of an independent flagship repository.

## Repository roles

Every listed artifact uses one of these labels:

| Label | Meaning |
| --- | --- |
| **Flagship** | Independent, maintained system representing a primary portfolio capability |
| **Case Study** | Public, bounded implementation demonstrating one product or engineering problem |
| **Teaching** | Educational material, examples, or curriculum rather than a production claim |
| **Research** | Active or released research with an explicit question, protocol, and evidence boundary |
| **Archived** | Read-only historical source retained for provenance; never presented as active work |

An **Active Build** is recorded as **Research** or **Case Study** with its implemented and planned capabilities explicitly separated.

## Link-only policy

- Flagship and independently maintained projects stay in their own repositories.
- The Hub links to the canonical repository and summarizes its role; it does not copy the project implementation.
- Cross-listed projects keep one canonical owner and may appear in another Hub only as a link.

## Private research

- Private work is described by research direction and maturity only.
- Public Hub pages must not expose private source code, assets, internal paths, credentials, or inaccessible repository links.
- A private project receives a public link only after an explicit release decision and a reproducibility, license, data, secret, and claims review.

## Synchronization rule

Update the README and index whenever a listed project:

1. publishes a release or changes maturity;
2. becomes archived or changes visibility;
3. moves to a new canonical repository;
4. changes its public name or repository URL;
5. gains or loses evidence supporting a featured claim.

## Review checklist

- [ ] Canonical link resolves.
- [ ] Status label matches the repository state.
- [ ] Implemented, measured, planned, and simulated claims are separated.
- [ ] Private work has no inaccessible link.
- [ ] Archived work is not shown as active.
- [ ] Cross-lab ownership is explicit.
